aiMenu2

選んで、タッチ、すぐ AI。Mac のどこからでも 300 以上の生成 AI モデルへ。

aiMenu2 について

aiMenu2 は、メール、ブラウザ、エディタ、表計算など、どのアプリで選んだテキストに対しても、ショートカットキーひとつで AI アシスタントを呼び出せる Mac 用のユーティリティです。「翻訳する」「調べる」「校正する」「要約する」などのメニューがはじめから入っていて、よく使うプロンプトは自由に追加できます。

AI への問い合わせには OpenRouter を使います。ひとつのアカウントで、ChatGPT、Claude、Gemini、Perplexity、DeepSeek、Grok など 300 種類を超えるモデルを、目的や予算に合わせて選べます。

Mac App Store で入手

インストールから 7 日間は無料でお試しいただけます（料金について）。

主な機能

どのアプリからでも呼び出し

テキストを選んでショートカットキーを押すと、そのテキストを使ったプロンプトを AI に送れます。サービスメニューやメニューバーからも使えます。

プロンプトテンプレート

よく使うプロンプトをテンプレートとして保存し、階層メニューから呼び出せます。マクロで、クリップボードの挿入や回答のコピー・読み上げなどを自動化できます。

300 以上のモデルと「おまかせ」

モデルは一覧から選べます。「おまかせ」にすると、質問の内容に合わせて OpenRouter が適したモデルを選びます。価格優先・速度優先などのプロバイダの選び方も指定できます。

Fusion（複数の AI に相談）

複数のモデルが同じ質問に Web を検索しながら答え、分析役が比べたうえで、選んだモデルが 1 つの回答にまとめます。各モデルの回答と分析も確かめられます。

画像の生成と続けての編集

画像を生成できるモデルで「〜の絵を描いて」と頼むと、回答の中に画像が表示されます。「その絵を青くして」のように、続けて描き直しを頼めます。画像はクリックで保存できます。

読み上げと音声入力

回答を macOS の音声か、OpenRouter の高品質な音声で読み上げます。マイクでの音声入力にも対応し、話し終えるたびに文字にしてプロンプトに追加します。

画像・PDF の添付

画像や PDF をプロンプトに添付できます。PDF を直接読めないモデルにも、OpenRouter がテキストにして渡します。

費用の表示

回答の最後に、使ったモデル名と費用（ドルと円）を表示します。トピックごとの合計や、月ごとの合計・クレジット残高も確かめられます。

トピック履歴とアーカイブ

会話はトピックとして保存され、続きから質問できます。大切な会話はアーカイブに分けて残せます。iCloud に保存して、複数の Mac で共有することもできます。

はじめに

aiMenu2 を使うには、OpenRouter のアカウントとクレジット（AI の利用料金の前払い）が必要です。

  1. OpenRouter でアカウントを作り、Credits のページでクレジットを購入します。
  2. aiMenu2 の「設定 > 一般」を開き、API キー欄の上の「OpenRouter にログイン…」を押します。
  3. ブラウザで OpenRouter の画面が開くので、ログインして許可します。aiMenu2 に戻ると、API キーが自動で設定されています。
  4. チャット画面の下のメニューから、使うモデルを選びます。迷ったら「おまかせ」を選んでください。
許可画面での上限と有効期限について：OpenRouter の許可画面では、作られる API キーに使用額の上限と有効期限を付けられます。付けた場合、上限に達するか期限を過ぎると aiMenu2 から AI を使えなくなります。あとから openrouter.ai/settings/keys で変更できます。

OpenRouter の Keys のページで作った API キーを、設定画面の API キー欄に貼り付けて使うこともできます。

使い方

テンプレートのマクロ

テンプレートのプロンプトに次のマクロを書くと、送信時に置き換えや動作の切り替えをします。テンプレートエディタの右クリックメニューからも挿入できます。

マクロ働き
{{clipboard}}クリップボードのテキスト（選んでいたテキスト）に置き換えます。
{{copy response}}回答をクリップボードにコピーします。
{{speech response}}回答を読み上げます。
{{hide thinking}}推論するモデルの思考の過程を表示しません。
{{effort high}}推論の強さを指定します。none・low・medium・high・max が使えます。
{{fusion}}そのテンプレートだけ Fusion を使います。
{{compact window}}チャット画面を小さな表示にします（{{minimize window}} も同じ）。
{{normal window}}チャット画面を通常の表示に戻します。

Fusion

チャット画面の下の人のアイコン（Fusion ボタン）を押してオレンジにすると、次の質問から Fusion を使います。各モデルの回答と分析は、回答の先頭に折りたたんで表示されます。

  • 「設定 > 一般」の「Fusion のパネル」で、品質重視（大きなモデル）か速度重視（軽いモデル）かを選べます。
  • 複数のモデルに問い合わせるので、費用は通常の 4〜5 倍ほどかかり、回答まで 1〜2 分かかることがあります。

音声入力

  • マイクボタンを押すか、control キーを 2 回押すと録音が始まります。
  • 話し終えて 2 秒たつと、その部分を文字にしてプロンプトに追加し、そのまま次の発話を待ちます。
  • 録音中にクリックするか control キーを 1 回押すと、すぐに区切って文字にします。
  • ダブルクリックするか control キーを 2 回押すと、録音を終えます。

費用の確認

  • 回答の最後に、その問い合わせの費用を表示します。2 回目以降の回答では、トピックの合計も表示します。
  • 「ファイル > 使用額…」で、OpenRouter のクレジット残高、API キーの今日・今週・今月の使用額、aiMenu2 が記録した月ごとの合計を確かめられます。

よくある質問

aiMenu2 の料金のほかに、費用はかかりますか？
はい。AI の利用料金は、OpenRouter のクレジットから問い合わせごとに差し引かれます。料金はモデルによって大きく違い、無料のモデルもあります。
質問しても答えが返ってきません。
OpenRouter のクレジット残高と、API キーに付けた上限・有効期限を確かめてください。「ファイル > 使用額…」でまとめて確認できます。別のモデルや新しいトピックで試すと、答えが返ることもあります。
音声入力が使えません。
「システム設定 > プライバシーとセキュリティ > マイク」で、aiMenu2 にマイクの使用を許可してください。
複数の Mac で履歴を共有するには？
「設定 > 一般」の「トピック履歴を iCloud に保存」をオンにします。バージョン 1.05 から保存形式が新しくなりました。新しい版と古い版の aiMenu2 では、履歴は別々になります。すべての Mac を新しい版にそろえてください。

料金

aiMenu2 は、月額 200 円または年額 1,500 円のサブスクリプションです。インストールから 7 日間は無料でお試しいただけます。

サブスクリプションは、現在の期間が終わる 24 時間前までに自動更新をオフにしない限り、自動で更新されます。解約は、App Store またはシステム設定の「Apple アカウント > サブスクリプション」からいつでもできます。詳しくは利用規約をご覧ください。

AI の利用料金は、上記とは別に OpenRouter にお支払いいただきます。
