aiMenu2 のプライバシーに関する方針

概要

aiMenu2（以下「本アプリ」）は、合資会社アートマン弐壱（以下「当社」）が提供する macOS 用アプリケーションです。当社はユーザーのプライバシーを尊重します。本アプリは当社のサーバーに接続せず、当社がユーザーの個人情報やプロンプトの内容を収集することはありません。

ただし、本アプリは AI の機能を提供するために、ユーザーが入力・選択した内容を、ユーザー自身の OpenRouter アカウントを通じて AI サービスに送信します。詳しくは以下をご覧ください。

当社が収集しない情報

当社は、本アプリを通じて以下の情報を収集しません：

  • 個人を特定できる情報（氏名、メールアドレス等）
  • プロンプト、AI の回答、添付した画像・PDF、音声の内容
  • OpenRouter の API キー
  • 位置情報、連絡先、カレンダーのデータ
  • アプリの起動回数・利用状況などの統計情報

OpenRouter と AI サービスへの送信

本アプリは、AI への問い合わせに OpenRouter を使用します。ユーザーが問い合わせを送信したときに限り、次の内容が OpenRouter に送信されます。

  • プロンプト、システムプロンプト、同じトピックの会話の履歴
  • ユーザーが添付した画像・PDF、および続けて編集するために送る生成画像
  • トピック名を自動で付けるための、最初の質問と回答

OpenRouter は、ユーザーが選んだモデルを提供する AI 事業者（OpenAI、Anthropic、Google など）に内容を転送します。Fusion を使った場合は、複数の AI 事業者に転送されます。これらの送信は、OpenRouter および各 AI 事業者のプライバシーポリシーと利用規約に従います。当社がこれらの内容にアクセスすることはありません。

OpenRouter の設定で、データを保持しない事業者だけを使うように制限することもできます。詳しくは OpenRouter のプライバシーポリシーをご覧ください。

音声入力と読み上げ

  • 音声入力：ユーザーが音声入力を始めたときに限り、マイクの音声を録音し、文字に起こすために OpenRouter に送信します。録音は文字に起こしたあとに削除します。マイクの使用には、macOS の許可が必要です。
  • 読み上げ：読み上げエンジンに macOS を選んだ場合、通信は発生しません。OpenRouter を選んだ場合は、読み上げる文章を OpenRouter に送信し、合成された音声を受け取ります。

OpenRouter へのログイン

「OpenRouter にログイン…」を使った場合、ブラウザで OpenRouter のログイン画面が開きます。ログインは OpenRouter のサイトで行われ、本アプリがパスワードを扱うことはありません。許可されると、本アプリは OpenRouter から API キーを受け取ります。そのため、ログインの間だけ、同じ Mac の中からの接続に限って受け付ける受け口（localhost）を開きます。

そのほかの通信

  • 為替レート：費用を円で表示するために、Frankfurter から米ドルと円の為替レートを取得します。個人情報は送信しません。
  • 表示用のライブラリ：回答を表示するためのライブラリ（Markdown・数式・コードの表示）を、CDN（jsDelivr、cdnjs）から読み込みます。
  • 購入：サブスクリプションの購入と確認は、Apple の App Store を通じて行われます。

Mac の中に保存するデータ

  • 設定と OpenRouter の API キーは、お使いの Mac の中に保存されます。
  • 会話の履歴（トピックとアーカイブ）は、お使いの Mac の中に保存されます。設定で iCloud への保存をオンにした場合は、ユーザーの iCloud Drive に保存され、Apple のプライバシーポリシーに従って管理されます。当社が iCloud 上のデータにアクセスすることはありません。
  • 本アプリが異常終了した場合の記録は、お使いの Mac の中に保存されるだけで、外部には送信されません。
