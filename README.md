# aiMenu2-docs

aiMenu2（macOS 用 AI ユーティリティ）のサポートページ。

- 公開 URL: <https://cometheart314.github.io/aiMenu2-docs/>
- App Store: <https://apps.apple.com/jp/app/aimenu2/id6744962163>
- 不具合の報告・ご要望・ご質問: [Issues](https://github.com/cometheart314/aiMenu2-docs/issues)

## 構成

```
docs/
├── index.html         # ブラウザ言語で ja/ または en/ へ自動リダイレクト
├── style.css          # 共通スタイル
├── appicon.png        # アプリアイコン
├── ja/
│   ├── index.html     # トップ・使い方・よくある質問・サポート (日本語)
│   ├── privacy.html   # プライバシーポリシー
│   └── terms.html     # 利用規約 (EULA)
└── en/
    ├── index.html
    ├── privacy.html
    └── terms.html
```

`docs/` フォルダが GitHub Pages の公開ソースです。
